# Privacy Policy — 3D Studio Pro

**Last updated:** 29 October 2026  
**Applies to:** 3D Studio Pro for Android, package `com.studio3dpro.app`, version 1.0.0

> Hosted version: https://fareza777.github.io/studio3dpro/privacy-policy.html

## Summary

3D Studio Pro is an on-device 3D creation tool. It has no account system, no cloud sync, no analytics and no crash-reporting SDK. Your models, rigs, animations and exports are never uploaded.

The app does contain advertising and an optional in-app purchase, which are the only reasons it uses the network:

- **Advertising.** Banners, interstitials and opt-in rewarded ads are served by Google AdMob. To serve and measure ads, Google may collect device and advertising identifiers, approximate location derived from IP, and ad interaction data, under the [Google privacy policy](https://policies.google.com/privacy). Scenes and files are not shared with the ad SDK.
- **Consent.** Where required (EEA, UK, Switzerland, some US states) a Google User Messaging Platform (UMP) consent message is shown before any ad is requested; ads load only once consent allows it. Choices can be changed in Settings > About > Privacy options.
- **Purchases.** The one-time "Remove ads" product ($4.99) is processed by Google Play Billing. The app receives only whether the product is owned; it never sees your payment details.

Buying "Remove ads" stops ad requests from the app. You can also watch a rewarded ad to pause banner and interstitial ads for 30 minutes.

## Data the app handles

| Data | Where it stays | Why |
|---|---|---|
| 3D models, rigs, animations and project files you create or import | App-private storage and the location you choose with the system file picker | To edit, autosave, and export your work |
| Base-colour textures you import | App-private storage / the project file | To display materials |
| Autosave snapshots and recent-project metadata | App-private storage | Crash recovery and reopening recent work |
| Viewport screenshots you explicitly export | The location you choose with the system file picker | To save an image |

The app reads only the files you select through Android's Storage Access Framework. It does not scan, index or upload your storage.

## What the app does not do

- No account, sign-in, email address or phone number.
- No upload of your models, textures, projects or exports.
- No telemetry, analytics or crash-reporting SDK beyond the advertising and billing SDKs described above.
- No access to contacts, location, camera, microphone, SMS or call logs.
- No sale of personal information by the developer.
- No behavioural profiling or tracking across apps or websites.

## Children

The app is a general-purpose creative tool and is not directed at children under 13. Because it collects no personal data, it does not knowingly collect information from children.

## Security

Project files and autosaves are stored in the app's private sandbox, protected by Android's app-isolation model. Files you export are written only to the destination you pick. You are responsible for the security of files you copy to shared storage, cloud drives or other apps.

## Your choices

- Delete individual projects with the app's project controls.
- Clear all local app data with Android Settings → Apps → 3D Studio Pro → Storage → Clear data.
- Uninstalling the app removes its private storage, subject to Android backup settings.
- You can revoke access to any document at any time through the system file picker; the app only retains the content you imported into a project.

## Android backup

The manifest enables Android's standard app backup (`allowBackup="true"`). If you have device backup enabled, Android may include app-private project files in your Google account backup according to your device settings. That backup is controlled by Android and your Google account, not by this app. Disable backup for this app in system settings if you do not want that behaviour.

## Changes

If a future version adds cloud sync, analytics or crash reporting, this policy will be updated before that version is published, and the Play Store data-safety declaration will be revised.

# Kebijakan Privasi — 3D Studio Pro

**Terakhir diperbarui:** 29 Oktober 2026

3D Studio Pro adalah alat pembuatan 3D yang berjalan di perangkat. Tidak ada akun, sinkronisasi cloud, analitik, atau pelaporan crash. Model, rig, animasi, dan hasil ekspor Anda tidak pernah diunggah.

Aplikasi memuat iklan dan menyediakan pembelian dalam aplikasi, dan hanya untuk itu aplikasi menggunakan jaringan:

- **Iklan.** Banner, interstitial, dan rewarded (opsional) disajikan oleh Google AdMob. Untuk menyajikan dan mengukur iklan, Google dapat mengumpulkan ID perangkat/iklan, perkiraan lokasi dari alamat IP, dan data interaksi iklan sesuai [kebijakan privasi Google](https://policies.google.com/privacy). Adegan dan file Anda tidak dibagikan ke SDK iklan.
- **Pembelian.** Produk sekali beli "Hapus iklan" ($4.99) diproses oleh Google Play Billing. Aplikasi hanya menerima status kepemilikan produk, bukan data pembayaran Anda.

Membeli "Hapus iklan" menghentikan permintaan iklan dari aplikasi. Anda juga dapat menonton iklan rewarded untuk menjeda banner dan interstitial selama 30 menit.

Aplikasi hanya membaca file yang Anda pilih melalui pemilih file Android. Model, rig, animasi, tekstur, autosave, dan tangkapan layar disimpan di penyimpanan privat aplikasi atau di lokasi yang Anda pilih saat mengekspor. Tidak ada akses ke kontak, lokasi, kamera, mikrofon, SMS, atau log panggilan.

Anda dapat menghapus proyek melalui kontrol proyek di aplikasi, atau menghapus semua data lokal melalui Pengaturan Android → Aplikasi → 3D Studio Pro → Penyimpanan → Hapus data. Menghapus aplikasi akan menghapus penyimpanan privatnya, tergantung pengaturan cadangan Android.

Jika Anda mengaktifkan cadangan Android, sistem dapat menyertakan file proyek privat dalam cadangan akun Google sesuai pengaturan perangkat Anda. Cadangan tersebut dikendalikan oleh Android dan akun Google Anda, bukan oleh aplikasi ini.
